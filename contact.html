FAQ
Is CardForge free to use? ▾
Yes. CardForge is free to use. Login uses only the sample user data included in the project.
Is my data stored anywhere? ▾
Signup data is not stored. Generated cards are saved only in your browser localStorage.
Can I export my card as an image? ▾
Yes. Saved cards can be downloaded as PNG using the download button.
Does the QR code work on all phones? ▾
Yes. The QR code opens the deployed GitHub Pages card URL, so it works on modern Android and iOS phones.
